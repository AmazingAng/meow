Meow is a notification companion for AI agents and developer workflows. It receives results, errors, and attention reminders; replies and decisions take place in the original tool on the user's computer. No Meow account or third-party AI account is required to review the iPhone app.

REVIEW ON AN IPHONE WITHOUT A COMPUTER
1. Launch the app. Keep the suggested server https://api.meow.blue and tap Get started. This creates an anonymous device registration.
2. Allow notifications when prompted (you can still inspect the inbox if notifications are disabled).
3. On Connect your computer, a Device Key and CLI instructions are shown. You do not need to install the CLI to review the app. Tap Next to reach Test connection.
4. Tap Send a test from this iPhone. This tests the server and push delivery without installing an agent. If the setup screen keeps waiting for a computer-originated test, tap Skip for now to enter the inbox.
5. Settings also contains Send a test notification. Use it to create a test message, view the inbox and open the full message. To inspect an alert outside the app, send the test and return to the Home Screen.
6. Inspect the view switcher, local search, notification details, read/delete swipe actions, sound preferences, and server settings. Grouped views become useful once several notifications share a session/project/source.

OPTIONAL COMPUTER INTEGRATION
The public installation instructions at https://meow.blue/ explain how to install the macOS/Linux CLI and connect an agent. Use the Device Key generated by the reviewing iPhone in your own terminal. No supplied demo credentials are needed. Never send Device Keys to us or include them in feedback.

The suggested official HTTPS server is running. Self-hosting is optional and no Apple Developer account is needed to use the official service. Time Sensitive alerts depend on iOS notification/Focus permissions. This app does not use Critical Alerts or provide phone-side approvals.
