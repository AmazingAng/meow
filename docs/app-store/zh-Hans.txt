DESCRIPTION
有消息，喵你一下。

Meow 把 AI 智能体的工作进展送到你的 iPhone。任务有新结果、遇到错误或需要你关注时，及时收到提醒。手机查看上下文，回到电脑继续，不必一直盯着终端。

连接你的工作流
通过 Meow 命令行工具接入 Claude Code、Codex 或 Cursor。脚本、构建任务和其他服务也可以通过 CLI 或 HTTP API 发送通知。电脑端支持 macOS 和 Linux。

让消息井井有条
按消息、会话、项目或 Agent 浏览收件箱。在手机本地搜索已下载的历史，离线也能查找。消息和分组支持标为已读，以及删除不再需要的内容。

读到完整结果
点开通知查看全文，支持 Markdown、代码块和表格。会话名、项目名和 Agent 信息，让你知道是哪项工作需要关注。

选择喜欢的提醒方式
使用猫叫声或系统默认提示音。重要消息可使用时效性通知，具体提醒方式由你的 iOS 通知和专注模式设置控制。

选择信任的服务器
可直接使用建议的官方服务器，也可以连接自托管的 Meow 服务器。无需创建个人 Meow 账号。发送的消息会在所选服务器上缓存，下载后的历史保存在 iPhone；数据处理与保存期限详见隐私说明。

Meow 负责通知；回复与决定仍在电脑上的原工具中完成。通知投递需要可用的网络连接和相应系统权限。
