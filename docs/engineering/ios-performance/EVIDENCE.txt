Failures found and resolved during verification
- Initial RED: 9 focused tests produced 14 behavioral failures, after repairing
  a URLProtocol fixture that had force-unwrapped individual request bodies.
  Body-stream normalization fixed that boundary; behavioral assertions were kept.
- Shared refresh initially failed the existing rate-limit cancellation test:
  cancellation must reach the shared task. Added a cancellation handler; the
  original expected history/load/error assertions now pass.
- An additional adversarial test reproduced newer foreground membership being
  lost after an older full snapshot. The verified arrival now retains membership.
- Search tests now await local projection rather than assume same-stack work;
  expected IDs and no-HTTP assertions remain. Legacy write fixtures explicitly
  simulate unsupported batches and populate remote membership. The receipt test
  permits reporting before counts finishes while checking identity at report start.
- First simulator run reused identical IDs/registration across UI cases; preserved
  phone read state contaminated later cases. Fresh installations fix isolation;
  UI assertions were not weakened. Selected-read success fixtures now return the
  required JSON acknowledgement rather than the old empty per-ID response.
- First coverage gate rejected an unexecuted store success statement: API package
  coverage does not instrument imported store code. Added the generated direct
  store selection/replay test; the threshold was not lowered.
- Some XCTest temporary-database teardown logs report unlinked SQLite sidecars;
  those paths belong to disposable test folders, not the app's persistent inbox.
  Existing unused-result and AppIntents metadata warnings remain. All assertions
  pass; no new production compile error was suppressed.

Limits / rollout
- No physical-device APNs, TestFlight distribution, minimum-iOS-17 device run or
  production-network stress test. Simulator/native evidence cannot prove delivery.
- No new dependency or capability requiring a supply-chain audit. Credentials and
  notification bodies are absent from diagnostics; fixtures use disposable values.
- SwiftUI/AppDelegate wiring is compiled and exercised in the simulator; scoped
  native line coverage does not measure every UI branch. A failed SQLite write
  retries dirty changes on the next persistence operation; it cannot promise
  durable storage while the filesystem itself remains unavailable.
- No retention, notification schema, CLI/hooks, header action layout, V1 interaction
  scope or phone-history-expiry rule changed. Server batching adds no DB migration.
